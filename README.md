# LITCHI STAR GAME STUDIO

> 荔枝和星星，都值得拥有。

这是 LITCHI STAR GAME STUDIO 的品牌标识与视觉语言展示页。页面以四芒星荔枝标识为核心，介绍品牌含义、设计方法、色彩与字体系统。

**Live site:** https://yayapao.github.io/litchi-star-website/

## Identity

- **Name:** LITCHI STAR
- **Category:** GAME STUDIO
- **Primary mark:** 桂味荔枝果壳与四芒星构成的原创标识
- **Palette:** Lacquer `#9B202A`, Ember `#D94A43`, Black Cherry `#26050A`, Ivory `#FFF0C8`, Leaf `#315B49`
- **Type:** Tektur, Instrument Sans
